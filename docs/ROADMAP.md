# Roadmap — Ondule

## Phase 1 — Atelier essentiel (Terminé)
- Dessin fluide à main levée + 6 animations en boucle parfaite
- Import d'image/dessin + cadrage interactif
- Sélecteur de ratio sans distorsion
- Export GIF & Vidéo côté client

## Phase 2 — Persistance & Flux créatif
- Sauvegarde locale automatique (`IndexedDB` / export projet `.ondule.json`)
- Duplication de styles et préréglages de pinceaux personnalisés
- Déplacement / redimensionnement d'un trait sélectionné

## Phase 3 — Export avancé
- Encodage MP4 hors temps réel via WebCodecs (quand disponible)
- Export GIF avec fond transparent
- Option palette de couleurs globale pour GIF ultra-léger
